# DA HelpHub screenshots

Place app screenshots in this folder so the root README can display them.

Recommended filenames:

```text
home.png
support-directory.png
courses.png
policy.png
mobile.png
```

Suggested capture list:

1. Home / simple mode.
2. Support directory.
3. Courses and programs.
4. Policy or safety page.
5. Mobile phone layout.

Before committing screenshots, remove anything private, sensitive, or personally identifying.
